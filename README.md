## Project Overview
A responsive FOSS Club events page featuring event cards, a professional contact section, and a registration redirect page. Built using semantic HTML and CSS Flexbox for responsiveness.

## Workflow: How to Clone and Contribute

### 1. Fork the Repository
Navigate to the [tech_interview_2026](https://github.com/FOSSCLUB-LBSITW/tech_interview_2026) and click the **Fork** button to create a copy in your GitHub account.

### 2. Clone to Your Local System
Run the following command in your terminal to bring the project to your machine:
```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/tech_interview_2026.git](https://github.com/YOUR_GITHUB_USERNAME/tech_interview_2026.git)
````

### 3. Make Changes

  * **Add a Contact Section:** Included a footer with club contact information.
  * **Add Event Cards:** Added a minimum of 4 cards with unique event images.
  * **Neat Alignment:** Used **CSS Flexbox** to ensure cards are aligned and responsive.
  * **Registration Redirect:** Configured buttons to point to a "Registrations will be opening soon" page.

### 4. Add, Commit, and Push

Stage your changes and save them to your fork using these commands:

```bash
# Stage all changes
git add .

# Commit with a clear message
git commit -m "Complete web development tasks and UI updates"

# Push to your GitHub fork
git push origin main
```

### 5. Create a Pull Request

1.  Go to the original repository on GitHub.
2.  Click the **Pull Requests** tab.
3.  Click **New Pull Request**.
4.  Click **Create Pull Request** after reviewing your changes.
